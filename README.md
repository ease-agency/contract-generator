# Contract Generator – Ease-Agency

Maakt PA- en klantcontracten.

- **Templates**: elk contract is een Google Doc in een Google Drive-map (instellen via *Instellingen*).
  De tool maakt een kopie van het template in de eigen Google Drive van de gebruiker (map
  "Contracten (Contract Generator)"), vult de gegevens in en downloadt een PDF. De opmaak komt volledig uit het template.
- **Geen contractteksten in deze repository.** Uitleg over variabelen en [ALS ...]-voorwaarden staat onder *Instellingen*.
- **PA-gegevens** komen na inloggen uit de Google Sheet en worden niet opgeslagen, ook niet in de browser.
- Toegang loopt via het Google-account van de gebruiker (Sheets alleen-lezen, Drive alleen-lezen + eigen aangemaakte bestanden).
